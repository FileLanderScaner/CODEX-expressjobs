# ExpressJobs Objection Handling

## Common Objections

| Objection | Response |
| --- | --- |
| "No conozco la plataforma." | "Justamente por eso lo hacemos manual ahora: te ayudo a publicar o armar el material sin que tengas que aprender nada." |
| "No quiero pagar antes." | "Podemos empezar con el paquete chico y dejar claro qué se entrega antes de cobrar el resto." |
| "No tengo tiempo." | "Te pido solo los datos básicos y yo preparo el texto. Lo revisás por WhatsApp." |
| "No sé si funciona." | "Es una prueba controlada. No prometo resultados mágicos, prometo dejarte publicado o con una pieza clara para vender." |
| "Ya tengo Instagram." | "Perfecto. La landing o banner apunta a que más gente llegue a tu WhatsApp desde un mensaje más ordenado." |
| "Está caro." | "Podemos arrancar con la opción de $500 UYU y medir respuesta." |
| "Después veo." | "Te puedo dejar reservado el paquete fundador hasta [FECHA]. Después ajusto precio o cupo." |
| "Quiero pagar por resultado." | "Para esta etapa cobro por preparación y publicación manual, no por resultado garantizado." |
| "No quiero poner datos." | "No pedimos datos sensibles. Solo lo necesario para redactar la oferta o publicación." |
| "¿Es producción?" | "No. Es una etapa controlada/preproducción con entrega manual y reglas claras." |
