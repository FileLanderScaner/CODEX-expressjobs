## Profile Title

## Profile Description

```text
Ayudo a negocios, emprendedores y servicios a tener una landing simple, clara y orientada a recibir consultas por WhatsApp.

Puedo entregar:
- Landing basica
- Textos comerciales
- Estructura de oferta
- CTA a WhatsApp
- Banner simple

Trabajo con entregas manuales y claras. No prometo resultados garantizados; entrego una pieza lista para compartir y medir respuesta.
```
