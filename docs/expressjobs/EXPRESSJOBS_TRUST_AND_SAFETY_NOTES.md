# ExpressJobs Trust And Safety Notes

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Safety Principles

- No guaranteed employment claims.
- No guaranteed income claims.
- No live payment claims.
- Keep users inside platform messaging where possible.
- Minimize personal data collection.
- Use reviews and reputation carefully; do not imply full verification unless verification exists.

## Risk Signals

- User asks whether payment is guaranteed.
- User wants to move immediately to external private contact.
- User shares sensitive personal data.
- User posts unsafe, illegal, discriminatory, or exploitative work.
- User complains that role or flow is unclear.

## Controlled Pilot Rules

- Use known testers first.
- Keep jobs low-risk and simple.
- Do not test dangerous physical tasks.
- Do not test emergency work.
- Do not process real payments.
- Have a manual support contact for pilot testers.

## Incident Response

1. Pause cohort expansion.
2. Record incident category and route.
3. Remove or hide unsafe test content if staging tools allow it.
4. Update copy, policy, or flow before continuing.
5. Escalate critical issues to release gate.
