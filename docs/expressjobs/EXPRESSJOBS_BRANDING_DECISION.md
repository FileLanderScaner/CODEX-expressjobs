# ExpressJobs Branding Decision

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Decision

Use **"Trabajos Rapidos"** as the public user-facing brand and keep **"ExpressJobs"** as the technical repository/project name.

Recommended display:

`Trabajos Rapidos by ExpressJobs`

## Reasons

- "Trabajos Rapidos" is clearer for Uruguay/LATAM users.
- It communicates the category without requiring English comprehension.
- ExpressJobs remains useful for repo, internal docs, branch names, and technical continuity.

## Risks

- Brand split can confuse docs if not consistently explained.
- "Rapidos" may imply immediate availability; copy must avoid guarantees.
- If future legal trademark checks fail, public brand may need revision.

## Approved Copy

- "Publica trabajos rapidos o encontra tareas cerca tuyo."
- "Conectamos personas que necesitan resolver tareas simples con trabajadores locales disponibles."
- "Publicar una tarea"
- "Buscar trabajos"
- "Preview privado - no produccion"

## Rejected Copy

- "Gana dinero garantizado"
- "Empleo asegurado"
- "Pagos protegidos"
- "Verificacion de identidad"
- "Soporte 24/7"
- "Trabajos ilimitados reales"

These claims are rejected until the product, operations, verification, and payment systems actually support them.
