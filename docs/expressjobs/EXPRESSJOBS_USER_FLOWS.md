# ExpressJobs User Flows

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Client Flow

1. Visit `/`.
2. Choose client in `/onboarding`.
3. Open `/client/jobs/new`.
4. Create a job draft/open job.
5. Open `/client/jobs/[id]`.
6. Review applications.
7. Accept a worker.
8. Move the job through the status flow.
9. Complete the job.
10. Leave a review.

## Worker Flow

1. Visit `/`.
2. Choose worker in `/onboarding`.
3. View worker profile in `/worker`.
4. Browse `/worker/jobs`.
5. Open `/worker/jobs/[id]`.
6. Apply to the job.
7. Use basic chat once participating.
8. Receive review after completion.

## Admin Flow

1. Open `/admin`.
2. View users.
3. View jobs.
4. View applications.
5. View events/disputes.
6. No destructive actions are available in the MVP.
