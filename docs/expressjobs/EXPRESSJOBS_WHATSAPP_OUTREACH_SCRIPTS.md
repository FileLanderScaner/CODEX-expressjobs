# ExpressJobs WhatsApp Outreach Scripts

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Rules

- Send only manually after preview/staging is ready.
- Do not mass-send.
- Do not claim guaranteed work.
- Do not claim guaranteed income.
- Do not mention live payments.
- Stop messaging if a person declines.

## Client Script

Hola, estoy haciendo una prueba controlada de ExpressJobs para publicar tareas locales rapidas. No hay pagos reales activos; buscamos feedback sobre si se entiende y genera confianza. Te puedo pasar el link de prueba cuando este listo?

## Worker Script

Hola, estamos probando ExpressJobs para que personas con oficios o disponibilidad encuentren tareas cerca. Es una prueba MVP, no garantiza trabajo ni ingresos. Te gustaria probar el flujo y decirnos si te postularias?

## Group Script

Hola vecinos, estamos validando ExpressJobs con un grupo chico de testers. La idea es publicar tareas locales y recibir postulaciones. Es una prueba controlada, sin pagos reales activos. Si alguien quiere probar como cliente o trabajador, me escribe por privado.

## Follow-Up Script

Gracias por probar. En una escala del 1 al 5, que tan claro fue el flujo? Que te hizo confiar o desconfiar? Que cambiarias antes de recomendarlo?
