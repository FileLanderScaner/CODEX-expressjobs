# ExpressJobs Tester Onboarding Guide

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Before The Test

Tell testers:

- This is an MVP test.
- Production is not live.
- Payments are not active.
- No employment or income is guaranteed.
- They should not share sensitive personal data.

## Client Tester Tasks

1. Open landing.
2. Choose client role.
3. Create a sample job.
4. Review applications.
5. Accept a worker in the controlled flow.
6. Check chat and review form.
7. Share what felt unclear or risky.

## Worker Tester Tasks

1. Open landing.
2. Choose worker role.
3. Review worker profile surface.
4. Open jobs list.
5. Open a job detail.
6. Try the application flow.
7. Check chat/review surfaces.
8. Share what felt unclear or risky.

## Admin Observer Tasks

1. Watch for confusion.
2. Record trust objections.
3. Record route or UI failures.
4. Do not collect unnecessary personal data.
5. Do not ask users to complete real payments.
