# ExpressJobs First 100 Users Plan

`PRODUCTION_STATUS=NO-GO_PRODUCTION`

## Audience

- Montevideo clients with small urgent tasks.
- Workers with existing informal service experience.
- Small businesses needing recurring local help.

## Rollout

1. Recruit 10 known client/worker pairs.
2. Manually observe job creation, application, acceptance, chat, completion, and review.
3. Expand to 30 users through WhatsApp groups and local communities.
4. Add category focus based on completed jobs.
5. Expand to 100 only after abuse/dispute handling is tested.

## Metrics

- Signup completed
- Role selected
- Job created
- Application created
- Application accepted
- Job completed
- Review created
- WhatsApp share clicked
